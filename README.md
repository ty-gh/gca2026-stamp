# gca2026-stamp — スタンプ集め（スマホ用ページ）

出張 高専ラボ with ICTパーク（GCA2026 秋・11/7・8 泉佐野オチアリーナ）のワークショップ「スイッチだけで足し算を作る」で使う、スタンプ集めのページ。

- 公開 URL: https://ty-gh.github.io/gca2026-stamp/
- `index.html` に `manifest.webmanifest` と `icon.svg` を添えた 3 ファイル。ビルド不要、サーバー不要。フォントだけ Google Fonts を読む（届かなければ端末のフォントで動く）
- 合言葉（NOT / OR / AND / XOR / 半加算器）を入れるとスタンプが押され、5 つそろうと賞状の画像を保存できる
- 名前は任意（ニックネーム）。端末の中にだけ残り、どこにも送らない

**正本は `ty-gh/ws-remote` の `gca2026-stamp/stamp-app/`。** 直すときはそちらを直して、3 ファイルをここへコピーして push する（数分で反映）。
仕様・変え方・できないことは、そちらの README にある。

## 公開のしかた

GitHub Pages。Settings → Pages → Build and deployment → Source を **Deploy from a branch**、Branch を **main / (root)** にする。

## 導入アニメーション（スタンプ集めとは別。ローカルで再生）

進行台本にあってスライド PDF にないパートを、HTML アニメーションにしたもの。ファイルをブラウザで開くだけで動く（`file://` のまま。サーバー不要、外部ライブラリなし）。
画面は 16:9 で描いて窓に合わせて縮むので、プロジェクターや PC 向き。`F` で全画面。見た目はスライド・スタンプ集めと同じ「紙」のテーマ。

| ファイル | 台本の場所 | 操作 |
| --- | --- | --- |
| `intro-zoom.html` | 導入-2 スマホ → 導入-3 中の板 → 導入-4 チップ → 導入-5 チップの中 → 導入-6 区画の中 → 導入-7 スイッチ（スライド 04 と 05 の間） | クリック / Space / → で 1 つ進む（「近づきます」が合図）。導入-7 は「一番奥にいたのは……」で止まり、クリックで「スイッチ 1 個」→ オン / オフ → 「ひとりでは何も計算できません」と進む。← で戻る、Home で最初、数字キー 1〜9 でその場面へ、A で自動（約 10 秒ずつ） |
| `intro-gather.html` | 導入-9 集まる（アニメ）（スライド 05 と 06 の間） | 開くとトーチ 1 本。クリック / Space で、トーチが四方から集まって 12×22 のブロックのスマホになる（約 11 秒、途中は自動）。R でもう一度。最後の絵はスライド 06 と同じ位置・マス目なので、そのままスライド 06 へ切り替える |

- 字幕の文は、各ファイルの `STEPS`（zoom）/ `showCap(...)`（gather）を直す。ブロックの並びは `intro-gather.html` の `MAP`（スライド 06 から写した）
- フォントだけ Google Fonts を読む。届かなければ端末の丸ゴシックで動く
