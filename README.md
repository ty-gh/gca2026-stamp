# gca2026-stamp — スタンプ集め（スマホ用ページ）

出張 高専ラボ with ICTパーク（GCA2026 秋・11/7・8 泉佐野オチアリーナ）のワークショップ「スイッチだけで足し算を作る」で使う、スタンプ集めのページ。

- 公開 URL: https://ty-gh.github.io/gca2026-stamp/
- `index.html` に `manifest.webmanifest` と `icon.svg` を添えた 3 ファイル。ビルド不要、サーバー不要。フォントだけ Google Fonts を読む（届かなければ端末のフォントで動く）
- 合言葉（NOT / OR / AND / XOR / 半加算器）を入れるとスタンプが押され、5 つそろうと賞状の画像を保存できる
- 名前は任意（ニックネーム）。端末の中にだけ残り、どこにも送らない
- 賞状の下に満足度アンケート（7 問・全部タップで 1 分・満足度だけ必須）。送信先は Google フォーム（下の「アンケートの送信先」）。名前は送らない

**正本は `ty-gh/ws-remote` の `gca2026-stamp/stamp-app/`。** 直すときはそちらを直して、3 ファイルをここへコピーして push する（数分で反映）。
仕様・変え方・できないことは、そちらの README にある。

## 公開のしかた

GitHub Pages。Settings → Pages → Build and deployment → Source を **Deploy from a branch**、Branch を **main / (root)** にする。

## アンケートの送信先

答えは Google フォーム（`index.html` の `SURVEY` に書いてある formResponse の URL）に送る。フォームの「回答」で見る。

- **設問と選択肢の文字は、フォームとページで同じにする。** 違う文字を送るとフォームが受け付けず、回答が消える。フォーム側の 1〜6 は必須なので、ページも 1〜6 を必須にしてある
- フォームの設問や選択肢を変えたら、`index.html` の `<section id="survey">` の `value` を同じ文字に直す。設問を足したら、フォームの「⋮ → 事前入力した URL を取得」で `entry.番号` を拾って `SURVEY.entry` と `SURVEY_KEYS` に足す
- 変えたあとは、公開 URL で 5 つそろえて送信し、フォームの「回答」に 1 件入るのを確かめる
- 送れなかったとき（電波が弱いなど）は端末に残り、次にページを開いたときに送り直す。同じ端末からは 1 回だけ（「はじめから」で消すと、また答えられる）。名前は送らない

| key | フォームの設問 | 選択肢 |
|---|---|---|
| `sat` | 1. 全体を通して、どれくらい満足しましたか？ | とても満足 / 満足 / どちらでもない / 不満 / とても不満（ページでは 5〜1 の丸） |
| `grade` | 2. 参加したお子さんの学年は？ | 未就学 / 小1・2 / 小3・4 / 小5・6 / 中学生以上 |
| `level` | 3. 内容のむずかしさはどうでしたか？ | かんたん / ちょうどよい / むずかしかった |
| `fav` | 4. 一番面白かったステージはどれですか？ | ① あべこべの回路（NOT回路） … ⑤ 1 + 1 = 10 ！？（半加算器） |
| `interest` | 5. 半導体やコンピュータの仕組みへの興味は湧きましたか？ | 湧いた / 少し湧いた / 変わらない |
| `again` | 6. またこのようなワークショップに参加したいですか？ | 参加したい / マイクラなら参加したい / あまり |
| `comment` | 7. 感想やご意見 | 自由記述（任意・300 字まで） |

フォームのヘッダー画像（1600×400）は `form/header.html` を Playwright で撮ったもの。文字や色を変えるときはそちらを直して撮り直す。
